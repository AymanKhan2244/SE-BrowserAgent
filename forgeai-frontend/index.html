FREQUENTLY ANSWERED QUESTIONS

How does SE Browser Agent differ from standard code autocomplete tools? +

Autocomplete tools suggest tokens as you type. SE Browser Agent is an autonomous execution loop: it accepts high-level objectives, generates code across files, opens an actual Chromium browser, inspects DOM elements, clicks buttons, observes errors, and iterates until the feature passes all end-to-end specifications.

Can the agent run inside our private GitHub Enterprise repositories? +

Yes. Through our GitHub App integration, you can grant scoped access per repository. Code is processed exclusively within temporary, zero-retention micro-VM sandboxes. Your proprietary code is never stored or used to train public foundation models.

What happens if the agent gets trapped in an infinite retry loop? +

The execution engine is bounded by strict step budgets and circuit breakers (defaulting to 10 iteration cycles or 5 minutes max per subtask). If a test suite cannot be healed, the agent rolls back its working tree, commits a detailed diagnostic trace to the PR comments, and alerts the engineering lead.

Which front-end frameworks and testing libraries are officially supported? +

Native integrations exist for Playwright, Cypress, Puppeteer, Vitest, Jest, Next.js, React, Vue, Svelte, Django, FastAPI, and Go Gin. Custom testing frameworks can be hooked in via a simple JSON-RPC configuration file.
